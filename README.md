# Glow Shop ✨

A kids' shop game (Portuguese UI): you run the cutest skincare store in town and help each customer choose the right products for their needs.

Run: open `index.html` in a browser, or `python3 -m http.server 5179` in this folder and open http://localhost:5179

- **Jogar**: serve 5 customers a day, fill their bag from the shelf and score points
- **Guia de Produtos**: learn which products help with each need
- Includes a safety tip: kids' skin is delicate, so always ask an adult before trying a new product

Everything lives in a single `index.html`.
